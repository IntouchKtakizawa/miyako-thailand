# Miyako Thailand — refined website

Modern Japanese-first static redesign of https://miyakothailand.com/.

## Preview

Run `python3 -m http.server 8765` in this folder and open http://localhost:8765.
No build or installation required. Compatible with GitHub Pages.

## Content

22 public WordPress pages and 362 public blog posts captured November 2, 2026. Full page details are accessible through the footer directory. Blog has keyword search. Original reservations, quotations and contact processing remain on the existing official website; this static site does not submit reservations. Embedded calendars, original images, external links and fonts require internet access.

The public HTML uses the custom miyako3.1 WordPress theme, jQuery 2.2.4, jQuery UI and several legacy layout scripts. This redesign replaces those layout dependencies with responsive CSS and vanilla JavaScript. Private PHP, database, credentials and WordPress admin code were not accessed.

This is a reviewable redesign, not a replacement of the company's live domain. The source content retains original wording, including historical pricing and notices. Confirm operational details with the company before switching production hosting. Content snapshots do not automatically sync subsequent WordPress changes.
